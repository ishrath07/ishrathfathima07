Fake Review Classifier

Code

Flags product reviews as genuine or fake across 40,432 labelled Amazon reviews. A TF-IDF + logistic regression baseline is compared against a fine-tuned DistilBERT, and an interpretability pass confirms the baseline keys on writing complexity rather than surface keywords. Side-by-side Gradio demo.

97% accuracy · 0.995 ROC-AUC (baseline: 93% · 0.982)
PythonDistilBERTscikit-learnGradioNLP

Support Ticket Triage

Code

Routes customer support tickets by category and urgency for small teams. A TF-IDF + LinearSVC baseline is benchmarked against fine-tuned DistilBERT — the baseline matched or beat the transformer on F1 while running far faster, which is the actual finding: match model complexity to data scale.

Baseline ≥ transformer on F1, at 40–70x the speed
